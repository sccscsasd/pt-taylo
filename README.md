# Português — карточки

Одностраничное веб-приложение для изучения европейского португальского (PT-PT).
Весь код — в одном файле `index.html`. Никакой сборки, никакого бэкенда.
Интерфейс в стиле iOS, светлая и тёмная тема переключаются автоматически по системной.

## Что умеет

- **Слово** — вводите слово или выражение (можно несколько через запятую). С третьей буквы
  появляются подсказки из встроенного словника A1–A2: диакритика не нужна, «pao» находит `pão`.
  Рядом с каждой подсказкой — уровень и тема, а уже добавленные слова помечены «уже в колоде».
  Выбор мышью, тапом или стрелками с Enter. Перевод, пример и заметку допишет модель.
- **Скриншот** — выберите картинку, вставьте её из буфера (Ctrl+V) или перетащите файл.
  Модель распознаёт текст, показывает его вместе с переводом на русский, а сам текст сразу
  попадает в разбор на слова — остаётся отметить незнакомые и создать карточки.
  Картинка перед отправкой сжимается до 1600 px по длинной стороне.
- **Текст** — вставляете абзац на португальском, приложение разбивает его на слова,
  отбрасывает служебные и уже знакомые, вы отмечаете незнакомые → карточки создаются пачкой.
  Предложение-источник передаётся модели как контекст, поэтому пример получается про ту же ситуацию.
- **Темы** — встроенный словник A1–A2 из Referencial Camões PLE: 1632 слова без повторов,
  разложенных по 18 темам (еда, дом, поездки, здоровье, время…). Выбираете тему,
  фильтруете по уровню, отмечаете слова — карточки создаются пачкой. Уже добавленное
  зачёркнуто. Подробности и исходные файлы — в [vocabulario/](vocabulario/README.md).
- **Карточки** — список с поиском, перегенерацией и удалением.
- **Учить** — четыре кнопки с фиксированным поведением:
  «Не помню» возвращает слово в текущую сессию через 10 минут, «Трудно» откладывает на день,
  «Знаю» — на 30 дней, «Легко» помечает слово выученным и убирает из показа. Карточки в сессии идут вперемешку, новые слова берутся случайно из всей колоды.
  Направление PT→RU, RU→PT или вперемешку, лимит новых слов в день.
- **Выученные слова сохраняются**: они не удаляются, а переезжают в раздел «Выучено»
  на вкладке «Карточки» (фильтр Все / Изучаю / Выучено). Оттуда любое слово можно вернуть
  в изучение одной кнопкой.
- **Настройки** — ключ, модель, лимит новых карточек в день, экспорт/импорт JSON.

## Готовая колода

`vocabulario/baralho-completo-A1-A2.json` — **1636 карточек**: весь словник A1–A2
с переводом, примером и заметкой, написанные вручную под европейскую норму.
Настройки → «Импорт». Без ключа, без затрат, дублей при повторном импорте не создаёт.
Те же карточки лежат и по темам (17 файлов `baralho-A1-*` / `baralho-A2-*`).

## Первый запуск

1. Откройте `index.html` в браузере.
2. **Настройки** → вставьте OpenAI API key (`sk-...`) → **Проверить ключ**.
   Должно появиться `Работает: спасибо`.
3. Модель по умолчанию — `gpt-4o-mini`: дёшево (~$0.0002 за слово) и умеет читать картинки.
   Распознавание скриншота стоит дороже текста — примерно $0.002–0.005 за картинку.

## Где живёт

Опубликовано на **https://pt.taylo.co** — GitHub Pages, репозиторий
[sccscsasd/pt-taylo](https://github.com/sccscsasd/pt-taylo), ветка `main`, корень репозитория.
Файл `CNAME` в корне задаёт домен; страница закрыта от индексации (`noindex`).

### DNS

Одна запись в панели GoDaddy (Domains → taylo.co → DNS → Add New Record):

| Type | Name | Value | TTL |
|---|---|---|---|
| CNAME | `pt` | `sccscsasd.github.io` | 1 час |

Корневой `taylo.co` не трогаем — он остаётся на конструкторе GoDaddy.
Через несколько минут после появления записи GitHub сам выпустит сертификат Let's Encrypt;
после этого включается «Enforce HTTPS» в настройках Pages.

### Обновление сайта

```bash
git add -A && git commit -m "..." && git push
```

Pages пересобирается за минуту.

### На телефоне

Откройте `https://pt.taylo.co` в Safari или Chrome → «Добавить на главный экран».
Приложение запустится в полноэкранном режиме. Первый шаг внутри — Настройки → «Загрузить
1636 карточек», затем вставить свой OpenAI-ключ, если нужны новые слова из текста и скриншотов.

### Локальный запуск

```bash
python -m http.server 8777
```

## Данные и синхронизация

Карточки, интервалы и настройки хранятся в `localStorage`, а поверх работает синхронизация
через Supabase — проект `taylo`, таблица `public.pt_sync`.

Как включить: Настройки → «Включить синхронизацию». Приложение сгенерирует код из 24 символов
и отправит колоду в облако. На втором устройстве — «Ввести код с другого устройства».
Дальше всё автоматически: изменения уходят через 2,5 секунды после последнего действия и при
сворачивании приложения, а при возвращении подтягиваются с сервера.

Что синхронизируется: карточки с прогрессом, настройки, OpenAI-ключ и дневной счётчик новых слов.
Ключ вводится один раз на любом устройстве и появляется на остальных сам.

Слияние без потерь: карточки сопоставляются по id и по слову, выигрывает версия с бо́льшим числом
повторений. Настройки берутся более свежие по метке времени. Двум устройствам можно работать
параллельно — прогресс не затрётся.

Как устроено на сервере: прямой доступ к таблице закрыт (RLS без политик), работают только две
функции `security definer` — `pt_pull(code)` и `pt_push(code, data)`. Чтобы прочитать данные,
нужно знать код: он и есть пароль. Публикуемый ключ Supabase в коде страницы — так и задумано,
без кода синхронизации он бесполезен.

Резервная копия по-прежнему доступна: Настройки → «Экспорт» / «Импорт».

### Ограничение бесплатного тарифа

Supabase усыпляет бесплатные проекты после недели без единого запроса — именно это случилось
с `taylo` до подключения. При ежедневных занятиях проект не заснёт. Если всё же заснёт,
синхронизация начнёт возвращать ошибку, а данные останутся целы: и локально, и в базе.
Разбудить — кнопкой Resume в панели Supabase.

## Безопасность ключа

Ключ хранится в браузере в открытом виде и уходит напрямую в `api.openai.com`.
Для личного приложения это нормально. Рекомендации:

- заведите отдельный ключ только под это приложение и поставьте лимит расходов;
- не открывайте приложение на чужих устройствах;
- если ключ утёк — отзовите его в панели OpenAI.
