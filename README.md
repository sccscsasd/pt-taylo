# Português — карточки

Одностраничное веб-приложение для изучения европейского португальского (PT-PT).
Весь код — в одном файле `index.html`, без сборки и зависимостей. Карточки и прогресс
живут в Supabase и принадлежат аккаунту, а не браузеру.
Интерфейс в стиле iOS, светлая и тёмная тема переключаются автоматически по системной.

## Что умеет

- **Слово** — вводите слово или выражение (можно несколько через запятую). С третьей буквы
  появляются подсказки из встроенного словника A1–A2: диакритика не нужна, «pao» находит `pão`.
  Рядом с каждой подсказкой сразу виден перевод, а уже добавленные слова помечены «уже в колоде».
  Выбор мышью, тапом или стрелками с Enter. Перевод, пример и заметку допишет модель.
- **Скриншот** — прикрепляется к той же строке, как вложение в чате: Ctrl+V, перетаскивание
  файла на поле или значок картинки в самой строке. Под строкой появляется миниатюра
  с крестиком, а кнопка справа превращается в «Распознать». Модель читает текст, показывает
  его вместе с переводом на русский, и текст уходит в разбор на слова — остаётся отметить
  незнакомые и создать карточки. Картинка перед отправкой сжимается до 1600 px по длинной стороне.
- **Текст** — абзац на португальском вставляется в ту же строку: пять слов и больше без
  запятых считаются текстом, а не списком слов. Приложение разбивает его на слова,
  отбрасывает служебные и уже знакомые, вы отмечаете незнакомые → карточки создаются пачкой.
  Предложение-источник передаётся модели как контекст, поэтому пример получается про ту же ситуацию.
  Отдельного поля для текста на экране нет: блок разбора появляется только тогда, когда есть
  что разбирать.
- **Темы** — живут прямо в тренировке, полоской над карточкой: «Все», 18 тем словника
  Referencial Camões PLE (еда, дом, поездки, здоровье, время…) и «Разное» для своих слов.
  Рядом с названием — сколько карточек темы ждут показа прямо сейчас. Нажали тему —
  сессия собирается только из её слов. Подробности и исходные файлы словника —
  в [vocabulario/](vocabulario/README.md).
- **Карточки** — список с поиском, перегенерацией и удалением. Поиск ранжирует выдачу:
  сначала слова, начинающиеся с запроса, потом совпадения в переводе, и только в конце —
  те, где запрос нашёлся внутри примера. Диакритика не нужна, «cao» находит `o cão`.
- **Учить** — четыре кнопки с фиксированным поведением:
  «Не помню» возвращает слово в текущую сессию через 10 минут, «Трудно» откладывает на день,
  «Знаю» — на 30 дней, «Легко» помечает слово выученным и убирает из показа. Карточки
  в сессии идут вперемешку, новые слова берутся случайно. Направление PT→RU, RU→PT или
  вперемешку. Дневного лимита новых слов нет: в сессию попадает вся колода или вся
  выбранная тема.
- **Выученные слова сохраняются**: они не удаляются, а переезжают в раздел «Выучено»
  на вкладке «Карточки» (фильтр Все / Изучаю / Выучено). Оттуда любое слово можно вернуть
  в изучение одной кнопкой.
- **Настройки** — на виду только направление тренировки и загрузка готовой колоды.
  Аккаунт, состояние синхронизации, экспорт/импорт и удаление колоды свёрнуты
  в раздел «Служебное».

## Готовая колода

`vocabulario/baralho-completo-A1-A2.json` — **1636 карточек**: весь словник A1–A2
с переводом, примером и заметкой, написанные вручную под европейскую норму.
Настройки → «Загрузить колоду A1–A2». Без ключа, без затрат, дублей при повторной
загрузке не создаёт.
Те же карточки лежат и по темам (17 файлов `baralho-A1-*` / `baralho-A2-*`).

## Первый запуск

1. Откройте https://pt.taylo.co и войдите под своим аккаунтом.
2. Колода и прогресс подтянутся из облака. Если аккаунт новый и колода пустая —
   Настройки → «Загрузить колоду A1–A2 (1636 слов)».
3. Ключ OpenAI вводить не нужно: он живёт на сервере, в секретах Supabase.
   Модель — `gpt-4o-mini`, около $0.0002 за слово и $0.002–0.005 за распознанный скриншот.

## Где живёт

Опубликовано на **https://pt.taylo.co** — GitHub Pages, репозиторий
[sccscsasd/pt-taylo](https://github.com/sccscsasd/pt-taylo), ветка `main`, корень репозитория.
Файл `CNAME` в корне задаёт домен; страница закрыта от индексации (`noindex`).

### DNS

Одна запись в панели GoDaddy (Domains → taylo.co → DNS → Add New Record):

| Type | Name | Value | TTL |
|---|---|---|---|
| CNAME | `pt` | `sccscsasd.github.io` | 1 час |

Корневой `taylo.co` не трогаем — он остаётся на конструкторе GoDaddy.
Через несколько минут после появления записи GitHub сам выпустит сертификат Let's Encrypt;
после этого включается «Enforce HTTPS» в настройках Pages.

### Обновление сайта

```bash
git add -A && git commit -m "..." && git push
```

Pages пересобирается за минуту.

### На телефоне

Откройте `https://pt.taylo.co` в Safari или Chrome → «Добавить на главный экран».
Приложение запустится в полноэкранном режиме. Войдите под своим аккаунтом — прогресс
подтянется из облака. Если колода пустая: Настройки → «Загрузить колоду A1–A2».

### Локальный запуск

```bash
python -m http.server 8777
```

## Доступ и аккаунты

Приложение закрыто: пока не выполнен вход, ничего не показывается. Регистрация отключена —
аккаунты заводит владелец в панели Supabase (Authentication → Users → Add user,
с галочкой Auto Confirm User). У каждого пользователя своя колода и свой прогресс.

## Данные и синхронизация

Карточки принадлежат аккаунту, а не браузеру. Истина — таблица `public.pt_cards`
в Supabase: одна строка на карточку, RLS пускает только к своим строкам
(`auth.uid() = user_id`), анонимный доступ не даёт ничего. В `localStorage` лежит копия
под ключом конкретного пользователя (`pt.cache.v2.<id>`), поэтому два аккаунта на одном
устройстве не перемешиваются, а после входа с нового устройства всё подтягивается само.

Обмен автоматический и точечный: оценка карточки отправляет одну строку, а не всю колоду.
Изменения уходят через полторы секунды после последнего действия, при сворачивании
приложения и перед выходом из аккаунта; при возвращении докачивается только то, что
изменилось с прошлого раза.

Без сети приложение продолжает работать из локальной копии: правки копятся в очереди,
в Настройках → «Служебное» видно, сколько их ждёт отправки, и уезжают они сами,
как только связь появится. Расхождения между устройствами решаются по времени правки,
а удаление доезжает до других устройств как надгробие (`deleted`), поэтому удалённая
карточка больше не возвращается.

## Ключ OpenAI

Ключа в браузере нет. Запросы идут в Edge Function `ai` (`supabase/functions/ai/index.ts`),
которая держит ключ в секретах Supabase и сама ходит в OpenAI.

Функция принимает только два режима — `cards` и `vision` — и защищена:

- обязателен токен вошедшего пользователя, публикуемый ключ проекта не подходит;
- не больше 20 слов и 4,4 МБ картинки на запрос;
- не больше `DAILY_LIMIT` запросов на пользователя в сутки (по умолчанию 300),
  счётчик в таблице `pt_usage`;
- модель фиксирована на сервере, по умолчанию `gpt-4o-mini`.

Настройка ключа: Supabase → Edge Functions → Secrets → `OPENAI_API_KEY`.
Там же можно задать `OPENAI_MODEL` и `DAILY_LIMIT`.

## Безопасность

- Ключ OpenAI живёт только в секретах Supabase; в репозитории и в браузере его нет.
- Вход обязателен, регистрация закрыта — посторонний не потратит ваш лимит.
- Поставьте на ключ лимит расходов в панели OpenAI: это последняя линия обороны.
- Публикуемый ключ Supabase в коде страницы — так и задумано, без входа он бесполезен.
