# Списки слов A1–A2 (европейский португальский)

Единого официального «списка всех слов» для португальского, как Goethe-Zertifikat Wortliste
у немецкого, не существует. Ближайшее к этому — **инвентарь понятий Referencial Camões PLE**,
официальный документ Instituto Camões (Португалия): для каждого уровня перечислена
лексика по смысловым категориям. Он и взят за основу.

## Файлы

| Файл | Что это | Объём |
|---|---|---|
| `camoes-A1-inventario.md` | Инвентарь A1 дословно, с рубрикацией (общие понятия + тематические: дом, еда, покупки, здоровье…) | ~800 позиций |
| `camoes-A2-inventario.md` | То же для A2 | ~1300 позиций |
| `temas-A1-A2.json` | **Основной файл**: 18 тем, слова без повторов, с уровнем A1/A2. Встроен в приложение | 1778 |
| `baralho-completo-A1-A2.json` | **Вся колода одним файлом**: перевод, пример с переводом, заметка. Написано вручную, импорт без запросов к API | 1636 |
| `baralho-A1-*.json`, `baralho-A2-*.json` | То же по темам, 17 файлов — если хочется добавлять частями | 1636 |
| `palavras-A1.txt` | Плоский список A1, по одному на строку | 719 |
| `palavras-A2-novas.txt` | Только то, что добавляется на A2 (без повторов из A1) | 1059 |
| `palavras-A1-A2.txt` | A1 + A2 одним списком | 1778 |
| `ciberescola-vocabulario-fundamental-A1.txt` | Независимый A1-список Ciberescola / DGE, выборка из корпуса «Português Fundamental» | 634 |

Списки собраны из инвентаря автоматически: снята разметка, раскрыты варианты через `/`
и запятую, убраны грамматические пометы, родовые окончания `(a)` и обрубки фраз
(`chegar à`, `estar na`). Дубли сведены: слово попадает ровно в одну тему — ту, где
встречается первой, а если оно есть и в A1, и в A2, остаётся за A1.

## Как загрузить в приложение

**Готовая колода без затрат.** Настройки → «Импорт» → `baralho-completo-A1-A2.json`.
**1636 карточек** — весь словник A1–A2 целиком, с переводом, примером и заметкой.
Ни одного обращения к API, повторный импорт дублей не создаёт.

Если удобнее частями — те же карточки лежат по темам:

| Уровень | Файлы | Карточек |
|---|---|---|
| A1 | `inicial`, `pessoal`, `casa`, `tempo`, `viagens`, `espaco`, `qualidades`, `saude`, `lazer` | 659 |
| A2 | `nocoes`, `pessoal`, `casa`, `tempo-dia`, `comida`, `lazer`, `viagens-saude`, `qualidades` | 977 |

Карточки написаны для европейской нормы: род и неправильное мн. ч., управление предлогом,
ложные друзья (`esquisito`, `constipação`, `preservativo`, `fato`, `simpático`), разговорные
формы (`giro`, `bica`, `miúdo`), реалии Португалии (`freguesia`, `multibanco`, `rés do chão`,
`pousada`, `esquentador`). Бразильских вариантов нет.

Два замечания:

- очень частотные служебные слова (`de`, `que`, `não`, `para`…) приложение отфильтровывает
  как стоп-слова — если они нужны карточками, добавляйте их через поле «Слово или выражение»;
- весь словник разом — это примерно $0.35 на `gpt-4o-mini`. Разумнее идти по одной теме.
